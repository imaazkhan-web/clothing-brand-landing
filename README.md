# ✨ Vogue Studio — Luxury Haute Couture Landing Page
> **High-Converting E-Commerce Landing Page for Premium Fashion Brands**

A high-converting, luxury fashion store landing page featuring interactive collection showcases, slide-out cart drawer, wishlist manager, customer reviews, and responsive mobile-first navigation.

## ✨ Features & Interactive Elements

- 🏆 **Announcement Ticker:** Live promo ticker with promo codes (`VOGUE10`) and free shipping threshold notice.
- 🛍️ **Interactive Cart Drawer:** Slide-out shopping bag with subtotal calculations, promo code application, and item removal.
- ❤️ **Wishlist Manager:** Real-time wishlist bookmarking with active count badge in navbar.
- 🔍 **Live Search Overlay:** Instant product search drawer with filter options.
- 🌟 **Featured Collections:** Festive Luxury, Pret Wear, Unstitched Fabric, and Bridal Couture showcases.
- 🧵 **Craftsmanship Storytelling:** Detailed section highlighting hand-embroidered heritage and luxury fabric quality.
- 📱 **Responsive Mobile Drawer:** Smooth mobile navigation menu for all screen sizes.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox & CSS Grid)
- **Typography:** Google Cinzel (Luxury Serif) & Plus Jakarta Sans
- **Icons:** Font Awesome 6.4 Free Solid & Regular
- **Scripting:** Vanilla JavaScript (Cart state management, DOM interactions)

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/imaazkhan-web/clothing-brand-landing.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd clothing-brand-landing
   ```

3. **Open in browser:**
   Open `index.html` directly in your browser.
